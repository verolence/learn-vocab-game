# Техническое задание MVP веб-игры “Изучение слов через голос”

## 1. Цель
Создать вертикальное веб-приложение (9:16) на Vanilla JavaScript, которое показывает английское слово и ждёт от пользователя его перевода на русский язык. MVP используется для демонстрации формата короткого видео для TikTok/Reels, поэтому основной фокус — на эмоциональном и визуально читаемом фидбеке, а не на полноценном продукте.

## 2. Словарь
- 5 слов: `apple → яблоко`, `dog → собака`, `house → дом`, `car → машина`, `water → вода`.
- Слова зашиты в массив и выбираются по порядку.

## 3. Механика игры
1. TASK: показываем слово (~0.5 сек)  
2. LISTENING: ожидаем голос пользователя (3–5 сек), показываем индикатор “LISTENING…” и таймер  
3. Проверка: сравнение распознанной речи с правильным ответом  
4. SUCCESS: при правильном ответе появляется добрый мем + звук успеха (~1–1.5 сек)  
5. FAIL: при ошибке или тайм-ауте появляется злой мем + fail-звук (~0.8–1 сек)  
6. После SUCCESS / FAIL → следующий раунд → TASK  
7. Игра циклична для всех слов, после последнего — restart

## 4. UI-состояния
- **TASK / LISTENING**: основной экран с словом, таймер и индикатор listening  
- **SUCCESS**: экран с добрым мемом и звуком успеха  
- **FAIL**: экран с злым мемом и звуком провала  
- Переключение экранов через CSS-класс `.active`

## 5. Аудио
- Фоновая музыка — непрерывно, loop, играет весь раунд  
- Звуки успеха и провала — отдельные аудио элементы, проигрываются только в SUCCESS / FAIL

## 6. Техническая реализация
- Язык: Vanilla JavaScript  
- HTML/CSS: фиксированный вертикальный контейнер, flex-центровка, display-none для скрытых экранов  
- Структура проекта:
/index.html
/style.css
/script.js
/assets/audio/bg.mp3
/assets/audio/success.mp3
/assets/audio/fail.mp3
/assets/images/good.png
/assets/images/bad.png
/README.md
- Голосовой ввод: Web Speech API (`ru-RU`)  
- Логика состояния: `TASK → LISTENING → SUCCESS/FAIL → NEXT WORD`

## 7. Цели для видео
- Игра читается без звука  
- Мемы создают эмоциональный отклик  
- Таймер и индикатор создают ритм  
- Видео вертикальное, короткое (15–30 сек), подходит для TikTok/Reels

## 8. Ограничения
- Нет меню, очков, прогресса, настроек  
- Минимум анимаций и визуального дизайна
- MVP предназначен только для демонстрации формата видео, а не для долгой игры
