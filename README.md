# Language Voice Game MVP

Минимальный прототип игры для изучения иностранных слов через голос.  
Пользователь видит английское слово → произносит перевод на русский → получает мгновенный фидбек через мемы и звуки.  

Игра динамически меняет фон и реагирует на ошибки, создавая эффект “живого растения”, чтобы удерживать внимание.

---

## Технологии

- **Vanilla JavaScript, HTML, CSS**  
- **Web Speech API** — распознавание речи  
- Аудио: звуки успеха/провала  
- Мемы: добрые/злые картинки за правильный/неправильный ответ

---

## Инструкция по запуску

1. Склонируйте репозиторий или скачайте проект.
2. Откройте терминал в папке проекта.   
3. Запустите локальный сервер Python командой python -m http.server 5500
4. В браузере откройте http://localhost:5500/
5. Разрешите браузеру использовать микрофон.  
6. Игра запустится автоматически.  
   - Английское слово появится на экране.  
   - Произносите перевод на русский.  
   - Получите мгновенный фидбек через мем и звук.  
7. Ошибки влияют на фон и “состояние растения”, чтобы мотивировать продолжать.

> ⚠️ В Chrome автоплей аудио может быть заблокирован — клик по странице включит звуки.

---

## Принципы реализации

- Каждое слово = отдельная сессия (`WordSession`) для корректной работы Recognition и таймера.  
- Одна активная сессия в момент времени → исключает наложение игр.  
- SUCCESS/FAIL срабатывают строго один раз.  
- Таймер и распознавание речи полностью останавливаются при переходе к следующему слову.
